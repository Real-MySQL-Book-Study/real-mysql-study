# Q1. MySQL 쿼리 실행 절차

MySQL에서 쿼리가 실행되는 과정은 크게
1. SQL 파싱
2. 최적화
3. 실행
의 3단계로 나뉩니다.

### 1단계: SQL 파싱 (SQL Parsing)
* **담당:** MySQL 엔진 (SQL 파서)
* **설명:** * 사용자가 요청한 SQL 문장을 쪼개서 최소 단위(Token)로 분리하고, 이를 바탕으로 **파스 트리(Parse Tree)**를 생성합니다.
    * 이 과정에서 SQL 문장의 문법 오류(Syntax Error)를 검사합니다.

### 2단계: 최적화 및 실행 계획 수립 (Optimization)
* **담당:** MySQL 엔진 (옵티마이저)
* **설명:**
    * 생성된 파스 트리를 확인하고, 통계 정보를 활용하여 가장 효율적으로 데이터를 처리할 방법을 결정합니다(**실행 계획 수립**).
    * **주요 최적화 작업:**
        * 불필요한 조건 제거 및 복잡한 연산 단순화
        * 여러 테이블 조인(Join) 시, 테이블을 읽을 순서 결정
        * 각 테이블의 조건과 통계 정보를 바탕으로 사용할 인덱스(Index) 결정
        * 가져온 레코드의 재가공(임시 테이블, 정렬 등) 필요성 판단

### 3단계: 실제 실행 (Execution)
* **담당:** MySQL 엔진 & 스토리지 엔진 (InnoDB 등)
* **설명:**
    * 옵티마이저가 만든 실행 계획에 따라 MySQL 엔진이 스토리지 엔진에게 데이터를 요청합니다.
    * 스토리지 엔진은 디스크나 메모리로부터 실제 데이터를 읽어와 MySQL 엔진(실행 엔진)에게 전달합니다.
    * MySQL 엔진은 전달받은 데이터를 최종적으로 필터링하거나 가공하여 클라이언트에게 반환합니다.
